# Registro de Paro de Línea (digital)

Formato digital de Paro de Línea con calendario. Cada día guarda sus paros.

## Archivos
- `index.html`: toda la aplicación (un solo archivo, sin instalar nada).

## Cómo publicarlo con GitHub Pages
1. En GitHub: **New repository**, nombre `paro-de-linea`.
2. **Add file → Upload files**, sube `index.html` y `README.md`, y da **Commit changes**.
3. Ve a **Settings → Pages**.
4. En **Branch** elige `main` y carpeta `/ (root)`, y da **Save**.
5. En 1 o 2 minutos la página queda en `https://TU-USUARIO.github.io/paro-de-linea/`.
6. Abre esa liga en la tablet, y en el menú del navegador elige **Agregar a pantalla de inicio**.

## Importante
- **Los datos se guardan en el navegador de cada dispositivo.** Lo que se captura en una tablet no lo ve otro equipo. Si se borran los datos del navegador, se pierden.
- **Para enviar un paro**, ábrelo y usa **Imprimir / PDF**.
- **Privacidad:** en un repositorio gratuito la página es pública. Los datos no se suben, pero cualquiera con la liga ve el formato vacío. Para que sea privada, GitHub Pages en repositorio privado requiere plan de pago.
- **Compartir paros entre personas** necesita un servicio de datos aparte (Firebase, Supabase o Google Sheets).
